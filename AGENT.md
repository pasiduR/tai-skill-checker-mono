# AGENT.md

This repository has separate frontend and backend instructions.

## Routing

- For any work inside `backend/`, read and follow:
  - `backend/AGENT.md`

- For any work inside `frontend/`, read and follow:
  - `frontend/AGENT.md`

## Cross-cutting tasks

If a task touches both frontend and backend:

1. Read both `backend/AGENT.md` and `frontend/AGENT.md`.
2. Respect the boundaries and conventions of each side.
3. Keep shared API contracts consistent between them.

## General Rule

Before modifying code, determine which part of the repository the task belongs to and follow that directory's `AGENT.md`.

Do not bypass or contradict the instructions defined in the frontend or backend agent files.
